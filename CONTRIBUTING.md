# Cómo contribuir

1. Crea una rama desde `main`: `git switch -c tipo/descripcion-corta` (`feature/`, `fix/`, `docs/`).
2. Instala y ejecuta en local: `npm install` y `npm run dev`.
3. Antes de abrir el Pull Request ejecuta `npm run verificar`: debe pasar todo.
4. Mensajes de commit en español, en imperativo y descriptivos ("Agregar galería de sesiones").
5. Fotos nuevas: WebP, nombre descriptivo en minúsculas con guiones, `alt` y entrada en `sitemap.xml`.
6. Abre el Pull Request con la plantilla; la CI debe quedar en verde.
